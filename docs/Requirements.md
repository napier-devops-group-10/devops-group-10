# Population Reporting System (Functional Requirements)

---

## 1. Introduction

This document describes the functionality implemented by the individual requirement classes in the Population Reporting System. Each class is responsible for retrieving and presenting specific population-related information from the World database.

The purpose of this documentation is to explain the role of each requirement class and provide an overview of the reports generated by the application.

---

## 2. Country Population Reports (Requirements 1–6)

This group of requirements focuses on retrieving country population information. The reports allow users to view countries according to geographical location and population size.

---

### Requirement 1: All Countries in the World

Class: Requirement1.java

Retrieves a list of all countries stored in the database. The countries are displayed in descending order of population, allowing users to identify the most populated countries first.

### Requirement 2: Countries in a Continent

Class: Requirement2.java

Retrieves all countries belonging to a specified continent. The results are arranged in descending order of population.

Input: Continent name.

### Requirement 3: Countries in a Region

Class: Requirement3.java

Retrieves all countries belonging to a specified geographical region. The results are arranged in descending order of population.

Input: Region name.

### Requirement 4: Top N Populated Countries in the World

Class: Requirement4.java

Retrieves the top N most populated countries in the world. The number of countries returned depends on the value supplied by the user.

Input: Number of countries (N).

### Requirement 5: Top N Populated Countries in a Continent

Class: Requirement5.java

Retrieves the top N most populated countries within a specified continent. This allows users to compare the most populated countries in a particular continent.

Inputs: Continent name and number of countries (N).

### Requirement 6: Top N Populated Countries in a Region

Class: Requirement6.java

Retrieves the top N most populated countries within a specified geographical region.

Inputs: Region name and number of countries (N).

## Summary

Requirements 1–6 provide country population reports at different geographical levels. Requirements 1–3 retrieve all matching countries, while Requirements 4–6 limit the results to the top N most populated countries.

---

## 3. City Population Reports (Requirements 7–16)

This group of requirements focuses on retrieving information about cities and their populations. The reports allow users to view cities according to geographical location and population size. Cities are organised in descending order of population, with the most populated cities appearing first.

---

### Requirement 7 – All Cities in the World

**Class:** `Requirement7.java`

Retrieves all cities stored in the database and organises them in descending order of population.

The report displays each city's name, country code, district and population.

### Requirement 8 – All Cities in a Continent

**Class:** `Requirement8.java`

Retrieves all cities located within a specified continent. The class joins the `city` and `country` tables to identify the continent associated with each city. Results are organised in descending order of population.

**Input:** Continent name.

### Requirement 9 – All Cities in a Region

**Class:** `Requirement9.java`

Retrieves all cities located within a specified geographical region. The class joins the `city` and `country` tables to filter cities according to their country's region. Results are organised in descending order of population.

**Input:** Region name.

### Requirement 10 – All Cities in a Country

**Class:** `Requirement10.java`

Retrieves all cities belonging to a specified country. The class joins the `city` and `country` tables to identify cities associated with the requested country. Results are organised in descending order of population.

**Input:** Country name.

### Requirement 11 – All Cities in a District

**Class:** `Requirement11.java`

Retrieves all cities located within a specified district. The class filters the city records using the district name and organises the results in descending order of population.

**Input:** District name.

### Requirement 12 – Top N Populated Cities in the World

**Class:** `Requirement12.java`

Retrieves the top N most populated cities in the world. The number of cities returned is determined by the value supplied for N. Results are organised in descending order of population.

**Input:** Number of cities (N).

### Requirement 13 – Top N Populated Cities in a Continent

**Class:** `Requirement13.java`

Retrieves the top N most populated cities within a specified continent. The class joins the `city` and `country` tables to identify the relevant cities and limits the results to the requested number.

**Inputs:** Continent name and number of cities (N).

### Requirement 14 – Top N Populated Cities in a Region

**Class:** `Requirement14.java`

Retrieves the top N most populated cities within a specified geographical region. The results are filtered by region and organised in descending order of population.

**Inputs:** Region name and number of cities (N).

### Requirement 15 – Top N Populated Cities in a Country

**Class:** `Requirement15.java`

Retrieves the top N most populated cities within a specified country. The class joins the `city` and `country` tables to identify the relevant cities and limits the results to N.

**Inputs:** Country name and number of cities (N).

### Requirement 16 – Top N Populated Cities in a District

**Class:** `Requirement16.java`

Retrieves the top N most populated cities within a specified district. The class filters cities using the district name and limits the results to the requested number.

**Inputs:** District name and number of cities (N).

### Summary

Requirements 7–11 retrieve all matching cities based on geographical location, while Requirements 12–16 retrieve only the top N most populated cities within the selected geographical scope.

The requirement classes retrieve city information from the database, return the results as collections of `City` objects and provide methods for displaying the information in formatted tables.

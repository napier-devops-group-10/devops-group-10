**Overview**

This project is a Java-based Population Reporting System developed as part of the DevOps coursework. It uses Maven for building the application, Docker for containerisation, and GitHub Actions for continuous integration.

**Technologies**

* Java 17

* Maven

* Docker and Docker Compose

* MySQL

* GitHub Actions
